# YouTube Interface — HTML & CSS
> 🔗 **Démo en direct :** Vous pouvez tester le site en ligne ici 👉 [https://ayamoustaquim.github.io/youtube-exercice/](https://ayamoustaquim.github.io/youtube-exercice/)

Reproduction de l'interface de YouTube réalisée avec **HTML et CSS** dans le cadre de mon apprentissage du développement web.

Le projet m'a permis de mettre en pratique les bases du développement front-end à travers la création d'une interface inspirée de YouTube.

## 🎯 Objectif

L'objectif de ce projet était de progresser en **HTML et CSS** en reproduisant une interface web réelle et relativement complexe.

J'ai notamment travaillé sur :

* la structure d'une page web avec HTML
* l'organisation d'un projet front-end
* les sélecteurs et classes CSS
* Flexbox
* CSS Grid
* le positionnement des éléments
* les images et icônes
* les boutons et interactions visuelles
* les effets `:hover`
* le responsive design avec les media queries
* l'utilisation de polices personnalisées
* l'organisation du CSS dans plusieurs fichiers

## 🛠️ Technologies utilisées

* HTML5
* CSS3

## 📁 Structure du projet

```text
Youtube-Exercice/
│
├── icons/
├── images/
├── intro-to-html/
├── photo-profil/
├── styles/
│   ├── buttons.css
│   ├── general.css
│   ├── header.css
│   ├── sidebar.css
│   ├── text.css
│   └── video.css
│
└── youtube.html
```

## 📱 Responsive Design

L'interface s'adapte à différentes tailles d'écran grâce aux **CSS Media Queries** et à l'utilisation de **CSS Grid** et **Flexbox**.

## 📚 Ce que j'ai appris

Ce projet m'a permis de passer de simples exercices HTML/CSS à la création d'une interface complète.

J'ai notamment appris à mieux comprendre :

* comment structurer une page avec HTML
* comment organiser plusieurs fichiers CSS
* comment construire des layouts avec Grid et Flexbox
* comment rendre une interface responsive
* comment utiliser les classes CSS efficacement
* comment reproduire une interface à partir d'un modèle visuel
